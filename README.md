A two-part micro-confession, typed once and never sent: a `To:` line naming
who it was meant for, and the unsent message itself.

```
To: My middle school best friend
I still have your Game Boy and I've been too ashamed to return it for nineteen years.
```

The confession is specific and honest — a borrowed Game Boy, kept for
nineteen years out of shame — and the reason it stayed in drafts is felt in
the words, not stated. The `To:` line and the message need each other:
swap the addressee and the confession stops making sense.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
